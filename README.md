# Unhas Club

Página de apresentação para serviços de nail design e divulgação de trabalhos.

**Acessar:** https://unhas-club.vercel.app

## Sobre a versão publicada

A demonstração funciona como vitrine de serviços. Informações de atendimento e disponibilidade devem ser confirmadas diretamente com a profissional.

## Repositório

O código da página ainda não foi separado e enviado para este repositório. O GitHub não identifica linguagens até que os arquivos da aplicação estejam versionados.

## Próxima revisão

Manter a apresentação alinhada com os serviços atuais e usar somente imagens autorizadas pela profissional.
